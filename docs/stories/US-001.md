## Story
As a registered user who forgot their password, I want to request a reset link by email, so that I can regain access without contacting support.

## Acceptance criteria
- Given a registered email, when the user requests a reset, then an email with a single-use link valid for 30 minutes is sent.
- Given an unknown email, when the user requests a reset, then the response is identical to the known-email case and no email is sent.
- Given a valid link, when the user submits a new password meeting policy, then the password changes and all sessions are revoked.
- Given an expired or used link, when it is opened, then the user sees an error and can request a new link.

## Edge cases
- More than 5 requests per hour per account or IP are rate limited.
- Link opened twice concurrently: only one submission succeeds.
- Email address casing and surrounding whitespace are normalised.

## Out of scope
- Reset by SMS, security questions, admin-initiated reset.
